# Synthetic restart evidence census

This fixture-only, disabled-by-default route reports a held coordinator-restart job only after authenticated exact claim, task/generation, finished commit permit, worker completion attestation and full coordinator spool byte/hash verification. The report is a point-in-time snapshot and always lists current node/source and physical engine fencing as unproven; it never changes or releases the hold, acknowledges Viewer custody, deletes data, or permits a job to resume. The completion is a worker attestation, not independent proof of NodeODM or source authenticity. The probe is not wired into the production runtime or an operator UI.

Any missing, stale, busy, altered, or malformed evidence is intentionally returned as a generic conflict, so it does not yet identify the exact failed prerequisite. This diagnostic limitation must be addressed before operator use. Spool validation reads all archive bytes and is bounded by the existing work semaphore but has no hard filesystem I/O deadline. The DB snapshot is point-in-time; fencing and authority may change after response. Report-time census uses no DB writes; test setup and constructors do. A close failure may leave an uncertain descriptor as described by the spool reader's existing limitations.
