## How to finish once answers arrive

1. Turn Hub labels and area answers into `labels.csv` (tree_id,label,group=area). Keep it on the Staging share, not in Git.
2. Run `treedar classify` on run-001 with the labels. Areas are held out as groups, and a final test set of areas is scored once. Report coverage and the calibration table.
3. Compare plot counts with the detections inside each plot square (`treedar benchmark` logic, or a direct count), using both presets.
4. Compare the 20 field heights with LiDAR heights, matching each field pin to the nearest tree top.
5. Write the numbers into `milestone-1-results.md`, without coordinates. Make the go/no-go call per `milestone-1.md`.

## Lessons recorded

The full log is in the Engineering Hub knowledge note `engineering-hub/projects/treedar-lab-notes.md`. The main lessons:
- **Crown photos:** cut them from the original photos (`treedar raw-chips`), not from the stitched ortho. The ortho smears leaning crowns (parallax).
- **ODM texturing:** it runs out of memory on Beau's PC. Use `treedar photo-ortho` instead.
- **WebODM:** exclude pre-takeoff photos with GPS (0,0), or it fails.
- **Hub image limit:** images must fit 256 KiB after the Hub re-encodes them at JPEG quality 75.
- **Hub decisions:** set `details`, `links` (absolute URLs only) and `allow_text` when creating a decision. They can't be added later.
- **Treetop window preset:** the broadleaf window merges young conifers in the planted block. The conifer preset over-splits big woodlot crowns. Choose per area once the plot counts exist.
